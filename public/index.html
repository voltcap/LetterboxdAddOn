Want to run your own copy?

No paid API or hosted account is needed to run this software. Download the GitHub source, install Node.js 20+, open a terminal in the project folder and run:

npm start

Then visit http://localhost:3000. The server must stay running. A local server is not publicly accessible: for Nuvio on another device or for clients requiring HTTPS, deploy your own copy to a public HTTPS host. Render is an optional self-deployment choice; see the repository README. The repository maintainer does not provide a hosted service.

02

Install in Nuvio

  1. Enter a public Letterboxd username above.
  2. Copy the generated manifest.json link.
  3. In Nuvio, open Addons and add an addon using a URL.
  4. Find Letterboxd Watchlist in your catalogs.

What is shared? Only publicly available watchlist movie information. This page has no analytics, cookies, passwords or user database. Your public username is included in the URL you install, so the add-on host and your app can see it.

What about playback? This is a movie catalog, not a streaming provider. Available playback depends on your other add-ons. Some films may lack compatible IMDb IDs.

Why might it be slow? New watchlists need film ID lookups. Letterboxd may also temporarily block automated requests, and free web hosts can go to sleep.
